# Third-party review ledger

This file is a review checklist, not a grant of rights. No public license is assigned by this bundle.

- OneEmo: base weights, tokenizer/processor and model implementation; retain upstream conditions.
- Transformers, PEFT, PyTorch and image/video libraries: verify exact installed distributions and notices.
- AffectGPT/OV-MER: pinned metric implementation and mapping assets; obtain upstream files separately.
- FACED/EAV: confirm approved access and any derived-data/model redistribution restrictions.
- Qwen, InternVL, AffectGPT and R1-Omni baseline source/model dependencies: isolate environments and
  preserve each upstream source/version; baseline adapters do not change the base model's license.

The snapshot contains the project's integration scripts, not third-party model repositories or weights.
